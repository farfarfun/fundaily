# fundaily

占位仓库，尚无实际功能代码。当前已在 PyPI 发布 `0.0.1` 空壳版本，用于保留 `fundaily` 这个包名；具体功能会在之后陆续补充。

## Install

```bash
pip install fundaily
```

PyPI：<https://pypi.org/project/fundaily/>

## 最小示例

当前仅有版本号可用，用来验证包已正确安装：

```python
import fundaily

print(fundaily.__version__)  # 0.0.1
```
